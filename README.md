# TurnoSmart V50 — Ecopack escalável

A V50 continua sendo o gestor de manutenção da Ecopack, mas passa a separar os dados específicos da empresa da lógica principal do aplicativo.

## Configurável

- empresa;
- unidade;
- departamento;
- setor;
- metas de OEE, MTTR, MTBF e confiabilidade;
- limite de OS atrasadas;
- limite de reincidências;
- conteúdo dos relatórios.

## Portabilidade

A configuração pode ser exportada em JSON. No futuro, uma nova empresa poderá importar um perfil próprio sem alterar o código-fonte.

As máquinas, TAGs, escalas e usuários da Ecopack continuam preservados.
